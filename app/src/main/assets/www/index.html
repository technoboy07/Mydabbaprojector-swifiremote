M2 Remote

Pair this phone

Open M2 Smart Remote on the projector. Scan its QR code with your camera, or type the 16-character code shown on the projector screen.

Accessibility service is off on the projector. D-pad, Back, Home, touchpad and text need it. Volume and media keys still work.
Move: 1 finger · Tap: click · Hold: long-press · Scroll: 2 fingers

This projector does not allow gesture injection, so taps and scrolling are unavailable. Pointer movement still shows the cursor.

Send text to the selected field

Replaces the text in the projector's focused text box. Works in standard Android text fields; some apps (games, many web/video apps) ignore it. Press OK on the projector's search button afterwards — there is no injectable Enter key.

Remote settings

Security: this page talks to the projector over plain HTTP on your local network. Every command is signed with a key that was never sent over the network, so it cannot be forged or replayed, but other devices on the same Wi-Fi can see which buttons you press and any text you send. Don't send passwords.
